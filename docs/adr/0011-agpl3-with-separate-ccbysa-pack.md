# The project is AGPL-3.0; the dictionary pack is a separate CC BY-SA artifact

Lekto's source is licensed **AGPL-3.0**. The network clause is mostly dormant for a
local-first app, but it is deliberate: if anyone ever runs Lekto as a hosted service, that
service's source must be offered back.

Consequences we accept:

- Every dependency must be **AGPL-compatible** for the way we link it. Apache-2.0 and MIT
  are fine; GPL-2.0-only is not. iText (AGPL-3.0) is licence-compatible where a PDF library
  is needed.
- AGPL §6 (installation information for "User Products") means we must not make modified
  versions impossible to install. Distributing through Play and F-Droid satisfies this.

The **dictionary pack is not part of the code**. It is derived from Wiktionary data, so it
is distributed as a **separate release artifact under CC BY-SA 4.0** with attribution,
generated by CI and downloaded on demand. App and pack are a *collection of separate works*,
not a combined work, so the share-alike obligation stays on the pack and never reaches the
AGPL code. Compliance to confirm before the first public pack release.
