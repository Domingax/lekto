# Lekto — Agent Guide

Lekto is a local-first immersive reading app for language learning (Android +
desktop). The product and UX are specified under `docs/`; engineering work is
planned and tracked with the skills in `.agents/skills/`.

## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles, default strings. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
